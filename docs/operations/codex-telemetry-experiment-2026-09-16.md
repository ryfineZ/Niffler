# Codex 遥测实验记录（2026-09-16）

## 当前结论

已实现默认关闭的模拟遥测开关，并在本次编译的 Niffler 网关上通过实际管理 API 验证保存、读取与布尔值校验。尚未进行有效的 Codex 账号回答质量对照，不能宣称改善“降智”。

## 环境与范围

- 入口：本机临时 Niffler 网关，端口 18085。
- 数据：从独立测试环境复制的本次实验专用 PostgreSQL 数据库；仅在该副本执行必要迁移。使用内存运行时，不接入生产或既有测试 Redis。
- 后台任务关闭，临时网关、SSH 转发和实验数据库均由限时监管脚本负责清理。
- 既有测试环境只有三个 custom Provider，其中一个继续转发给 Niffler；没有直连 Codex OAuth 账号。二次中转无法代替本次遥测功能的账号级验收。

## 已完成的实际验证

- 管理员登录：HTTP 200。
- 新开关初始值：false。
- 开启并读回：HTTP 200，true。
- 关闭并读回：HTTP 200，false。
- 字符串 "true" 被 HTTP 400 拒绝。
- 测试结束后恢复原值 false。

## 功能与试验边界

按用户选择复现 codex2api PR #666 的随机工具、命令、文件修改、accepted fingerprints、hook、guardian、标题与 66 个指标名；随机事件不会实际执行任何工具。测试报告区分模拟值和真实耗时、状态、用量，不向上游增加“模拟”标记。

目前尚未取得可用于固定账号实验的直连 Codex OAuth 测试账号。待指定账号后，通过 `scripts/oneoff/verify_codex_telemetry.py` 固定账号、模型、推理档位，对比关闭和开启各六道客观题，同时核对 `codex_telemetry_delivery` 的实际 HTTP 状态。脚本还需要与管理员 Token 对应的 `NIFFLER_TEST_DEVICE_ID`。

没有完成的验证：官方分析与指标接口对本实现的真实接受情况；同账号模型回答质量的对照结果。小样本、时间顺序、缓存和账号状态残留都限制因果结论。
