# 后台钱包用户检索与用户创建时间展示

## 目标

后台钱包相关列表需要能按用户名、邮箱或用户 ID 找到对应记录；用户管理列表和详情里的创建时间需要显示到具体时间，便于管理员定位用户注册和资金动作。

## 非目标

- 不改变钱包、订单、退款的数据结构。
- 不改变资金扣费、退款审批或充值到账逻辑。
- 不新增后台权限。

## 行为变化

- 钱包列表、资金流水、退款审批和充值订单接口增加 `user_search` 查询参数。
- `user_search` 在数据库层匹配用户名、邮箱、用户 ID；涉及独立密钥钱包时，也匹配密钥名称和密钥 ID。
- 钱包管理里的资金流水、退款审批、充值订单页面增加用户搜索输入，输入后回到第一页查询。
- 用户管理列表和用户详情里的创建时间从“只有日期”改为“日期 + 时间”。

## 影响范围

- 后台钱包管理页面。
- 后台用户管理页面。
- 钱包和支付订单的后台读取接口。
- PostgreSQL 仓库和内存仓库的查询结构保持一致。

## 验证方式

- 前端类型检查通过。
- 后端编译检查通过，确认新增查询参数的所有结构体初始化都已补齐。
- 手动验证钱包管理输入用户名、邮箱或用户 ID 后，资金流水、退款审批、充值订单列表按用户过滤。
