# 管理员请求回放

## 目标与非目标

管理员从历史请求详情重新发送已保存的完整请求，明确看到发送状态、上游结果和错误。修复 Rust 后端只返回 dry-run 计划、前端却按真实响应显示的问题。

复用当前网关的格式转换、OAuth、请求规则、代理/隧道和执行运行时，不另建 HTTP 客户端。管理调试不进入用户账单结算，不改变原请求和原扣费。真实调用仍消耗上游额度。不扩展原本需要专用执行器的图片、音视频、Kiro/Antigravity/Grok 协议；不支持的目标在执行前返回明确错误。

## 行为与接口

- `POST /api/admin/usage/{id}/replay` 真正执行一次请求；保留 provider_id、endpoint_id、api_key_id、body_override 参数。不自动重试，避免重复消耗。
- 不指定目标时优先原端点/原账号；显式选择提供商且未指定账号时，选择该提供商已启用且未过期的兼容账号，跨提供商不得沿用原账号 ID。选中的账号必须属于目标提供商且启用、支持目标格式。支持 OpenAI Chat/Responses（含 Codex OAuth）、Claude Messages、Gemini 以及执行层支持的 embedding/rerank 标准格式。
- 使用完整客户端请求体和其 API 格式，经现有转换规则生成目标请求。缺失、过期、截断或非对象请求体阻止发送；不从计费元数据拼造请求。
- 原提供商/原端点沿用原映射模型；切换目标或覆盖模型时重新解析目标模型映射。请求路径使用目标格式对应的 URL 构建器，Responses 不得拼成 chat/completions。
- JSON 返回 `replay_id`、`original_request_id`、`status`（success/failed）、可空的 `status_code`、`response_headers`、`response_body`、`response_time_ms`、`error_message` 和 mapping。预检失败返回 4xx；上游 HTTP 或流内错误作为执行结果返回，HTTP 200 本身不代表模型完成。
- 流式上游由执行层收集，完成后一次返回聚合响应；保留工具调用等非文本输出。流内错误、提前断流、无内容及非 JSON 错误内容要可见，不伪造成功。上游执行最长 120 秒（提供商配置更短时以该配置为准）；前端请求超时为 180 秒，留出加载、认证准备及结果记录的时间。
- 每次执行使用独立编号，在现有请求链路记录中保存开始/结束状态及原 usage_id/request_id 关联。记录不绑定原用户计费身份，不保存认证头。执行前记录失败则不发送；执行后记录失败须返回明确提示，避免用户误以为没有发送而重试。
- 回放窗口独立加载完整请求详情，显示加载、缺失、失败和可重试状态；请求未就绪时禁用发送。发送时显示等待和耗时；完成后展示明确成功/失败文字、HTTP 状态和结果。旧服务返回 dry_run 时提示未实际发送，避免空白误报。

## 影响范围与验证

变更仅覆盖管理员回放接口、执行结果解码及回放窗口；复用的底层执行器和账单结算流程不改变。模型映射读取共用现有解析实现。

使用本地模拟上游验证实际收到请求、路径、认证、完整正文与流模式，覆盖 JSON、Responses 流完成/工具调用/失败/提前结束、HTTP 错误、超时、请求体缺失/截断、账号归属和跨提供商选择。核对独立链路记录及原 usage 不变。前端组件测试操作加载、发送中、成功、失败、空体及关闭后过期响应，运行类型检查和直接相关后端测试。临时服务仅使用五位数端口并自动清理。

## 执行记录

- 已定位：回放路由只生成 dry-run；详情正文延迟加载未接入回放窗口；前端没有兼容 dry-run 的状态判断。
- 已确认：执行运行时可收集流式字节，直接调用不进入用户计费结算。
- 已实现：真实执行、当前账号认证与代理、目标格式 URL/正文转换、Codex 工具开关、独立执行记录、流式结束与错误判定，以及前端完整正文加载和状态反馈。
- 前端验证：回放组件 7 项测试、usage API 契约 2 项测试通过；相关文件 ESLint、TypeScript 类型检查通过，生产构建通过（仓库原有 Browserslist 和大包提示仍存在）。
- 浏览器验证：独立本地组件预览验证发送中、成功、HTTP 200 流内失败、完整正文缺失状态，观察暗色桌面布局及工具调用内容。
- 后端验证：`cargo test -p aether-gateway --lib replay --offline` 的 20 项测试全部通过，覆盖真实发送、跨格式转换、Codex 工具配置、流式结果判定及超时记录。
- 提交检查：Rust 全仓库格式检查、网关全部目标 Clippy 静态检查（警告视为失败）通过。
- 临时项清理：本地预览使用 18471，测试上游使用 18100–19099 并随测试自动关闭；预览与专用浏览器会话已关闭、临时预览入口已删除。
- 未部署，未向真实付费上游发起验证请求。专用图片/音视频及 Kiro、Antigravity、Grok 执行器不在本次扩展范围。
