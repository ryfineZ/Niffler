# 管理端用户资金、套餐和号池可视化调整

## 目标

- 管理员在用户列表可以直接查看用户的钱包流水和套餐记录。
- 管理员可以编辑用户已有套餐的开始时间、到期时间和额度上限，避免只能取消后重新发放。
- 用户已有套餐的可用号池不能单独修改，统一跟随套餐管理中的当前号池配置。
- 号池管理页能直观看到当前提供商下各订阅类型、各账号状态的数量，并可点击筛选列表。
- 号池里的英文处理中数量改成中文说明，表达为当前正在处理的请求数量。

## 非目标

- 不改变套餐购买、支付、扣费规则。
- 不把套餐和钱包合并成同一种余额。
- 不新增跨提供商的全局账号统计，避免每次打开号池页扫描全部提供商。
- 不改变号池调度算法，只改善管理端查看和筛选。

## 行为变化

- 用户资金抽屉增加“套餐记录”页签，显示该用户所有套餐记录，包括生效、取消、过期记录。
- 用户套餐弹窗增加“编辑”操作；编辑只允许调整当前记录的时间和额度上限，不允许改成另一个套餐。
- 用户套餐编辑不显示号池选择，也不接受号池覆盖参数。修改套餐号池时，管理员在套餐管理中统一设置，所有有效老套餐从下一次请求开始生效。
- 如果要换套餐类型，仍使用“取消旧套餐 + 发放新套餐”的方式。
- 号池账号列表接口返回当前提供商的统计汇总；前端按这些统计展示筛选按钮。
- 点击订阅类型或账号状态统计，只过滤当前提供商账号列表。

## 影响范围

- 管理端用户列表和资金抽屉。
- 管理端用户套餐发放/取消弹窗。
- 管理端号池账号列表。
- 后端管理接口和数据层套餐记录读写。

## 性能约束

- 套餐记录按单个用户查询，不进入请求转发链路。
- 号池统计只针对当前打开的提供商账号计算，不按页面分页结果临时凑数。
- 账号统计复用号池列表读取到的账号状态，不引入请求前额外数据库查询。
- 用户资金流水仍走分页，不一次性读取全部流水。

## 验证方式

- 后端测试覆盖套餐记录编辑、取消后记录仍可查询。
- 前端类型检查覆盖新增接口和组件属性。
- 构建验证管理端页面能正常编译。
