# 管理后台表格宽度规则

## 目标

- 数据表格默认使用页面可用宽度，不能因为某个单元格内容较长而把整张表无限撑宽。
- 号池管理在桌面宽度下同时显示账号、额度、统计、导入时间、最近使用、评分、状态和操作列。
- 套餐管理在桌面宽度下同时显示套餐、价格、有效期、权益、排序、状态和操作列，列间距以快速比较为准。

## 非目标

- 不改变号池数据、套餐数据、筛选条件、排序规则或管理操作。
- 不取消确实需要横向滚动的宽表；这类页面继续显式声明自己的最小宽度。
- 不调整移动端现有卡片布局。

## 行为变化

- 公共表格不再默认使用内容最大宽度。
- 普通表格默认贴合容器宽度；页面需要宽表时，使用明确的 `min-width`，不能依赖公共组件无限扩张。
- 号池管理保留现有固定列宽和列宽调整能力；套餐管理保留七列百分比分配。

## 影响范围

- 公共表格组件的默认宽度规则。
- 所有使用公共表格组件的页面；已经明确设置最小宽度的宽表行为不变。
- 重点复查号池管理和套餐管理桌面页面。

## 验证方式

- 组件测试确认公共表格默认没有内容最大宽度，并允许页面显式设置最小宽度。
- 前端类型检查、测试和正式构建通过。
- 在桌面浏览器中确认号池管理与套餐管理的完整表头位于页面可视区域内，页面没有异常的超宽横向内容。
