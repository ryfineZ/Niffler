# 号池账号表格自适应布局

## 目标

- 号池账号表格中的短内容列按实际内容占用宽度，账号列使用剩余空间。
- 当前页全部账号都没有额度信息时，不显示空的额度列。
- 保持账号状态、统计、排序、筛选和操作能力不变。

## 非目标

- 不改变号池调度、额度刷新和账号状态的业务规则。
- 不改变移动端账号卡片布局。
- 不新增账号字段或修改接口数据结构。

## 行为变化

- 桌面账号表格不再使用固定百分比列宽，也不再从浏览器存储恢复旧的手工列宽。
- 选择框、额度、统计、时间、分数、状态和操作列按内容需要收缩；账号列使用剩余宽度。
- 当前页只要有一个账号包含额度进度、额度状态或额度更新时间，就显示额度列；否则整列隐藏，不保留空白占位。

## 影响范围

- 仅影响管理端“号池管理”的桌面账号列表。
- 原有列排序、状态筛选、账号操作和移动端展示保持不变。

## 验证方式

- 测试确认桌面表格使用自动列宽，不再带固定表格布局和持久化列宽。
- 测试确认有额度数据时显示额度列，没有额度数据时隐藏额度列。
- 运行号池管理页面的相关测试、类型检查和格式检查。
