# 成本倍率与套餐续费

## 目标

- 支持在提供商上配置默认成本倍率，用于计算平台真实成本。
- 支持在提供商的单个模型上覆盖成本倍率。
- 用户再次购买同一个套餐时按续费处理，不再让未到期套餐立即失效。

## 非目标

- 不改变用户分组的销售倍率规则。
- 不改变套餐可用模型范围规则。
- 不改变失效账号自动清理规则。

## 行为变化

### 成本倍率

平台真实成本按下面顺序取倍率：

1. 单个提供商模型的成本倍率。
2. 提供商默认成本倍率。
3. 服务账号/API 格式成本倍率。
4. 默认 `1`。

用户扣费仍按模型官方价格和用户分组销售倍率计算；成本倍率只影响平台成本、利润统计和后台分析，不展示给普通用户。

### 套餐续费

用户购买或管理员发放同一个套餐时：

- 如果当前同套餐还没到期，新权益从当前到期时间后开始，时长继续顺延。
- 如果当前同套餐已经到期，新权益从支付成功或后台发放时间开始。
- 同一用户同一时间只能有一个有效套餐；已有其他有效套餐时拒绝购买或发放。

## 影响范围

- 后台提供商表单新增默认成本倍率。
- 后台提供商模型表单新增模型成本倍率。
- 支付成功和后台发放套餐时，写入权益开始时间和到期时间会按续费规则计算。
- 套餐购买提示文案明确为“同套餐续费顺延；已有其他有效套餐时不能购买”。

## 验证方式

- 单元测试覆盖成本倍率优先级。
- 单元测试覆盖同套餐续费顺延。
- 前端类型检查和构建通过。
- 后端格式化和相关测试通过。
