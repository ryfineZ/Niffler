# 未登录 AI 请求保护

## 目标

- 未提供有效用户或 API Key 的 AI 请求，不再写入使用记录。
- 未登录 AI 请求按 IP 做短窗口限速，减少扫描请求占用网关资源。
- 邀请中心展示可直接复制访问的完整邀请链接。
- 套餐购买提示明确说明“同套餐续费会顺延；已有其他有效套餐时不能购买”。

## 非目标

- 不改变已登录用户的正常请求计费、使用记录和失败记录。
- 不改变套餐购买后的续费顺延规则。
- 不新增 Cloudflare、Caddy 或服务器级防火墙规则。

## 行为变化

- 未登录 AI 请求仍会返回业务错误，但不会出现在“使用记录”里。
- 同一 IP 的未登录 AI 请求超过限制后直接返回 429。
- 这类请求会写入安全类结构化日志，方便后续按日志系统检索。
- 如果历史或异常路径里已经写入了未认证 usage，管理端显示为“未认证请求”，不能显示成“已删除用户”。
- 客户端错误提示使用面向用户的说法，说明“Niffler 未收到可识别的 API Key”，不直接暴露内部原因描述。
- 明确缺少认证上下文的 AI 请求返回 401，不返回 503，避免误导为上游服务或供应商调度故障。
- 邀请链接没有 `Origin` 请求头时，会用当前请求的 Host 拼出完整地址。

## 影响范围

- 影响入口网关的 AI 请求入口。
- 影响用户邀请中心链接显示。
- 影响用户购买套餐页面的提示文案。

## 验证方式

- 增加后端测试，验证未登录 AI 请求不会写入使用记录。
- 增加后端测试，验证未登录 AI 请求超过 IP 限制后返回 429。
- 增加后端和前端测试，验证未认证 usage 不显示为“已删除用户”。
- 增加后端测试，验证缺少认证上下文的 AI 请求返回 401。
- 增加后端测试，验证邀请链接在没有 `Origin` 头时仍返回完整 URL。
- 运行前端类型检查，验证套餐提示文案改动不破坏页面。
